日程助手 · 全应用简化：13 个面 → 3 页 + 2 个全局入口 + 3 个浮层模板

前面只看「今日页」，这一版把整个应用摊开算账：现在一共 3 个底层页 + 14 个浮层，其中 6 个功能都有 2–3 个入口（同一件事在三个地方能点）。 简化不是把页面做短，而是给每个面一个唯一职责、给每个功能一个唯一入口。

建议 · 一句话职责 + 一个入口

3 页各干一件事
今日 现在做什么
唯一时间流（三段壳：现在卡固定 / 中间滑 / 展开全部）。搬出：学期大卡、录音列表、练耳全量、导入导出、设置。
周课表 这周怎么排
周网格 + 第 N 周切换；「其他日程」并进 ＋ 的选单（不再占一个分段位）。搬出：与今日页重复的问候卡。
我的 数据在哪 + 怎么改
只留 3 块：数据（导入/导出/备份）· 外观与提醒（主题、课前提提醒、复盘时间、常驻状态框）· 关于。搬出：录音历史 → 录音页；练耳 → 练耳页；学期信息 → 周课表。
2 个全局入口（不再到处放按钮）
录音键 今日 + 课表右下悬浮
手动录音的唯一入口；到点自动录音由「现在」卡自己长出来。
通知栏状态框 系统层，自己出现
三枚按钮（开始录音 / 上完了 / 我去听了）——这就是「到点」场景的唯一入口，App 内不用再复制一套。
14 个浮层收敛成 3 个模板
编辑模板 → 覆盖 7 个 确认模板 → 覆盖 2 个 选择模板 → 已统一
编辑模板 = 标题栏 + 字段区 + 固定 footer（删除 / 取消 / 保存）；4 个功能页（打卡、复盘、清单、练耳）升成二级页，统一返回键与标题栏，不再各写一套底部抽屉。
一套行规格（高度可预测）
课程 / 待办 / 练耳到期 / 复盘，全天都渲染成同一种 26px 时间行（已完成只占一行灰字）。 今日页「时间流」、周课表「其他日程」、清单页三处共用同一个行组件——页面高度从此可预测，也不会再出现「一个功能一种长相」。
