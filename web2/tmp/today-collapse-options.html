做法：滚一点点就把整块头部塌成一条 32–40px 的摘要条（状态点 + 课名 + 剩余 + 录音钮）， 再滚一点这条也走掉。
好处：等于把今日页变成「一条状态 + 全屏列表」，一屏 7 条。
代价：问候语、日期、学期进度、地点、今日计数全都看不见了 —— 只剩一条线时，「今天是几号、第几周」 这类信息要用户切走再切回来才看得到。
三个方向共同的三个必须钉住的点（不管选哪个）：
  • 录音中 / 复盘按钮不能被收掉。顶卡上那几颗钮（data-today-rec-start / data-today-rec-stop / data-review-start）在任何收缩档位都必须还在，而且触区 ≥44px —— 正在录音时最不该去猜按钮在哪。建议：录音中直接锁住收缩（停在展开态），录完再恢复联动。
  • 滚动窗口要跟着长高。现在的滚动窗口高度是 innerHeight − 今日页顶 − 导航 − 8，按「头部展开态」一次性算死的（App.vue:190 function measureTodayH()，且偏移量只涨不跌）。头部一旦会变矮/上移，这个高度必须同步加上「省掉的那部分」，否则底部会空出一条。
  • 切 tab / 切页面要复位。切到「周课表」再切回来、或点开详情浮层回来，头部必须回到展开态，而且滚动位置与头部形态要一致（不能出现「头是压扁的、列表却停在顶部」）。
