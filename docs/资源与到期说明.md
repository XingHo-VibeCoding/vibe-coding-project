## 4. 两条「没有开通」的注意事项

实测 `tcb env detail -e <env>` 与 `tcb env info`：

1. **数据库显示 `[Not enabled]`** —— 但云同步（P7）**实际在用** `sync_docs` 表（走 PostgREST/Postgres）。这是 CloudBase 控制台的显示口径问题（本项目用的是「数据库」资源，但环境详情页没把它列为已开通模块）。⇒ **别被这句话骗了**：`/api/sync` 能读写，说明表是真实存在的。
2. **Log Service `[Not enabled]`** —— 云函数日志服务未开通。⇒ 排查线上问题时**没有云端日志可查**，只能靠云函数返回的 `message` 字段（这也是为什么 `cloudfunctions/*/errors.js` 把错误文案写成人话）。

## 5. 导出数据：三条命令各管一样

### 5.1 静态网页（`/app/`）

```bash
# 列出线上有哪些文件
tcb hosting list -e vibecoding-test-d5fqmhbb955e19dd

# 下一步操作：tcb hosting download（注意是 download，不是 get）
#   子命令：(默认) 下载文件/目录，--dir 表示下载目录
tcb hosting download app/index.html ./backup-app/index.html -e vibecoding-test-d5fqmhbb955e19dd
tcb hosting download app ./backup-app --dir            -e vibecoding-test-d5fqmhbb955e19dd
```

**两条已实测**：单文件下载得到 `614 B`（与线上 `app/index.html` 一致）；`--dir` 下载整个 `app/` 目录成功（得到 index.html + 4 个 assets 文件）。

> **更省事的办法**：网页产物是可复现的 —— 仓库里有源码，重跑 `cd web2 && npm run build` 就能重建 `web2/dist`。
> **真正的底牌是归档目录**（已入库，见 `docs/回滚手册.md`）：**当前用 `release-archive/v1.1/`**（2026-10-13 深夜建立，含三个 bug 修复 + 原生控件清零；v1.0 是更早的里程碑，别拿它回退），那三个文件的 sha256 与线上一致，直接从仓库拿就行，不必从云端下载。

### 5.2 云同步数据（`sync_docs` 表）

同步数据是**按同步串（= 用户口令）派生的 `owner_uid` 分片**存的，一个口令一条记录。导出走 PostgREST（**已实测 200 可用**；`CLOUDBASE_API_KEY` 在本机 `cloudbaserc.json` 的 `functions.*.envVariables` 里，别贴到公开地方）：

```bash
# 基址口径见 cloudfunctions/sync/db.js:82
B="https://vibecoding-test-d5fqmhbb955e19dd.api.tcloudbasegateway.com/v1/rdb/rest"
curl -s "$B/sync_docs?select=*" \
  -H "apikey: <CLOUDBASE_API_KEY>" -H "Authorization: Bearer <CLOUDBASE_API_KEY>"
```

> 返回的是一个 JSON 数组，每条 = 一份同步文档（`owner_uid` / `doc` / `doc_rev` / `updated_at`）。**当前实测为空数组 `[]`**（还没人真正用同步串上传过数据）。

> 更实际的做法：**在 App 里用「我的 → 数据与导入导出」导出 JSON**（那是同一条数据的本机视角，不需要碰云端凭据）。
> 只要同步串还在手上，也能随时用 `/api/sync` 的 GET 把整份文档拉回来。

## 6. 到期前的动作清单（到 2027-03 之前做）

1. **到期前 30 天**（约 2027-03-01）：腾讯云会发通知，确认续费或迁移。
2. 若不再续费：按 §5 把三样东西（网页产物 / 同步数据 / 函数代码）各留一份在本机或仓库。
   - 网页产物 → 重建或从 `release-archive/` 取；
   - 同步数据 → App 里导出 JSON；
   - 函数代码 → 仓库里本来就有。
3. 云函数、网关、静态托管**随环境一起释放** —— 环境一到期，公网链接立即失效。
4. **不会自动扣费爆表**：体验版是预付套餐（`prepayment`），用完额度是**停服**而不是转按量计费。

```bash
export E=vibecoding-test-d5fqmhbb955e19dd
```
