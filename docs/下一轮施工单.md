## 3. 逐条明细

### P1 release 签名包

- **做什么**：`keytool` 生成 keystore（**放仓库外**，不进 git）→ 壳仓 `android/app/build.gradle` 加 `signingConfigs.release` + `buildTypes.release` → `assembleRelease` → 拷成 `dist-apk/schedule-v1.42.2-YYYYMMDD-release.apk`。
- **怎么算过**：`aapt2 dump badging` 显示证书非 debug；真机 `dumpsys package com.llltl6.schedule` 的 `installerPackageName` 不再是 `null`、「允许设置闹钟和提醒」开关**可点**（这是清单 #9 的根治）；`verify-apk.py` exit 0。
- **代价与坑**：**签名变了 ⇒ 首装必须卸载旧包 ⇒ 本机 localStorage 全丢**。固定顺序：先在旧包「导出回写主项目」+ 截图存现行数据 → 卸载 → 装 release → 导入。debug 包与 release 包**不能互相覆盖安装**（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`）。
- 不做的话：#9 只能教用户手动去系统设置开一次「允许受限制的设置」。

### P2 练耳记号可见可撤销

- **现状**：记号是 `web2/src/data/statusFrame.js:44-50` 的 `{date, classDone, listenDone}`（按天存），`web2/src/App.vue:677` 处理 `listenDone`。用户在通知栏按了「我去听了」之后，**App 里看不到、也撤不了**（当天不再提醒）。
- **做什么**：练耳二级页 `web2/src/pages/sub/ListenPanel.vue` 顶部加一行「今天已去听过 · 撤销」；撤销写回 statusFrame，当天允许再提醒一次。
- **怎么算过**：新脚本断言「有记号 → 显示 → 撤销 → 记号消失且不再抑制提醒」；截图。

### P3 真机坑 B：录音中常驻小条命中区偏移（**唯一未修的视觉缺陷**）

- **现象**：`data-rec-banner`（`web2/src/App.vue` 里 `fixed inset-x-0 bottom-20 z-[60] mx-auto w-fit`）在真机上**画在待办筛选 chips 上层，点它却落到 chips 上**；点小条**上方约 80 CSS px**（physical ≈ 2400）才生效 ⇒ 命中区整体比画面高约 120 physical px。
- **已排除**：①去掉 `<Transition name="fade">` 包层；②用 `inset-x-0 mx-auto w-fit` 替掉 `left-1/2 -translate-x-1/2`（去 transform）—— 两层都**无效**。电脑侧 `web2/tmp/status-frame-check.mjs` 的 C4 用 Playwright 点它**通过**。详见 `docs/交接说明.md` §6.4。
- **做什么**：真机连上后 `chrome://inspect` 远程调试 WebView，取该点的 `document.elementFromPoint(x,y)` 与 `getBoundingClientRect()`，和视觉位置逐项对照，判明是「合成层命中偏移」还是「布局视口高度差（WebView 高度含被系统 nav 遮住的部分）」。
- **退路（定位不出就换实现）**：把「去停」做成**非 fixed** 的流内元素（例如挂在 header 下方或底部 nav 上方参与布局），或整条小条改挂 header。
- **怎么算过**：真机上点小条的**画面位置**能进「课堂录音」二级页；`status-frame-check.mjs` 仍全绿（或补一条真机断言）。
- **依赖**：`adb devices` 要能列出设备（上次为空，本轮没验成）。

### P6 手机使用时间栏
