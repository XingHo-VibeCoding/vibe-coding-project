## 2. 代码结构（Stage 9 重构之后）

- `web2/src/App.vue` —— **4136 行**，唯一的「状态容器」：
  - 3 个底层页外壳：`<main data-page="today|week|me">`（非当前页带 `inert`）
  - 二级页容器：`<Teleport to="body">` 里的 `[data-sub-page][data-sub="…"]`，内含 4 个 `<XxxPanel>`，外面包了 `<Transition name="push">`（美术收口 2a）

- `web2/src/pages/` —— `TodayPage.vue` / `WeekPage.vue` / `MePage.vue` / `OnboardingPage.vue`
- `web2/src/pages/sub/` —— 4 个二级页：`LecturesPanel.vue`（课堂录音）/ `ListenPanel.vue`（碎片练耳）/ `TodosPanel.vue`（待办清单）/ `SettingsPanel.vue`（设置）
- `web2/src/sheets/` —— **12 个浮层**：`AddSheet` `ConfirmClearSheet` `DeleteLectureSheet` `DetailSheet` `EventSheet` `HabitSheet` `PickerSheet` `PressTypeSheet` `ReviewGridSheet` `ReviewSheet` `SemesterSheet` `TodoSheet`
- `web2/src/components/` —— `BottomSheet.vue`（所有浮层共用的壳）/ `RowItem.vue` / `DropdownSelect` / `MonthCalendar` / `NumberWheel` / `PeriodsEditor` / `TimeWheel`
- `web2/src/composables/app-ctx.js` —— APP_CTX 的 key
- `web2/src/data/` —— `store.js`（localStorage 读写 + 迁移）、`mock.js`（示例数据）、`statusFrame.js`（通知栏常驻状态框 / 处理记号）
- `web2/src/style.css` —— 主题 CSS 变量与动效类（`.fade` `.slide-*` `.push-*`）

**必须守住的不变式（踩过坑）**：

1. **26px 细行只有一个实现**：`web2/src/components/RowItem.vue`。别再复制一份。
2. **二级页必须 `<Teleport to="body">`**，并且带 `:style="{ paddingTop: 'var(--sat, 0px)' }"` —— 不然真机上「‹ 返回」会压在系统状态栏上（浏览器里 `--sat` 是 0，看不出来；`web2/tmp/safe-area-check.mjs` 专门盯这个）。
3. **录音入口只有 3 处**：今天页现在卡按钮 / 课表页正在上的课块 / 通知栏状态框。不许加 FAB、不许加自动录音开关；复盘不常驻。
4. **不再用 alpha 档底**：不要再写 `bg-ink/5`、`bg-ink/10`、`bg-ink/[0.06]` 这类；用 `bg-soft` / `bg-soft-2`（`src/style.css` 里逐主题定义的不透明实色 token）。批量替换工具：`web2/tmp/alpha-to-soft.mjs`。
5. **改 App.vue 的顶层声明/导入**（增删 `const`/`function`/`import`）后，必须重跑 `node tmp/gen-app-ctx.mjs --check`，它必须 exit 0；否则组件里 `const { … } = toRefs(app)` 会拿到 undefined（Vue 会吞掉 TypeError，页面只是空白，**不会**报 pageerror）。

### 6.3 真机坑 A：屏幕最下约 130px 是系统手势带，落在里面的 tap 不生效 —— **已加垫但机制未定论**

已做的缓解（2026-10-06）：`web2/src/components/BottomSheet.vue` 统一加 `padding-bottom: max(24px, calc(var(--sab, 0px) + 24px))`，12 个浮层一起受益。**但 `--sab` 目前没有生产者**（壳仓 `shell.js` 只写 `--sat`；Capacitor StatusBar 的 `toJSObject` 只回 height，`styles.xml` 也没开 edge-to-edge），所以这个垫子现在等价于固定的 24px，**能否躲开手势带未在真机复验**（当时 `adb devices` 为空）。

### 6.4 真机坑 B（**唯一未修的视觉缺陷**）：录音中常驻小条的命中区偏移

- 现象：`data-rec-banner`（`src/App.vue` 里 `fixed inset-x-0 bottom-20 z-[60] mx-auto w-fit …` 的红色小条）在真机上**画在待办筛选 chips 上层，但点它会落到 chips 上**；点小条**上方约 80 CSS px**（physical 2400 附近）才生效。命中区整体比画面高 ~120 physical px。
- 电脑侧测不出来：`web2/tmp/status-frame-check.mjs` 的 C4 用 Playwright `locator.click()` 点它**通过**。
- 已试过、**无效**的两种改法：①去掉 `<Transition name="fade">` 包层；②用 `inset-x-0 mx-auto w-fit` 替掉 `left-1/2 -translate-x-1/2`（去掉 transform）。
- 要真定位得做**真机 WebView 命中测试专项**（`chrome://inspect` 远程调试真机 WebView，看 `document.elementFromPoint(x,y)` 在那一点返回谁、以及 `getBoundingClientRect` 与视觉位置差多少）。
- 规避：录音中想停下，点小条**上方**一点，或直接从通知栏/课程页停。

### 6.5 小产品缺口：练耳「我去听了」不可见、不可撤销

`src/App.vue:677` 处理的 `listenDone` 记号写在 `src/data/statusFrame.js:44-50`（`{ date, classDone, listenDone }`，按天存）。用户在通知栏按了「我去听了」之后，App 里**看不到这个记号、也没法撤销**（当天不再提醒）。可考虑在练耳页显示「今天已去听过」并允许撤销。

### 6.6 安装侧：Android 13+「受限设置」会锁灰精确提醒开关

清单 #9：debug 侧载包在 `dumpsys package` 里 `installerPackageName=null` → Android 把它当受限来源，把「允许设置闹钟和提醒」锁灰（**App 侧入口与自检都正常**）。两个方向：①让用户手动开一次「允许受限制的设置」；②**做 release 签名包**（自签 keystore）根治。

## 8. 和这位用户协作的纪律（照 `AGENTS.md`，很容易踩）

1. **一天一份清单**：用户把当天的任务清单整块发来，那就是唯一范围；清单外的「顺手优化」先问，别自己动手。
2. **一次只做一个步骤**：做完停下，报告「做了什么 / 改了哪些文件 / 怎么验证（用户能亲眼确认的结果）」，然后**等用户说「进入下一板块」**，不要连做。
3. **人机分工**：要用户手动做的（注册、点按钮、装软件、截图）不要替他做，也不要假装完成；只讲清步骤、预期现象和坑，然后停下等。
4. **要用户拍板**：选方案/起名字/定风格，列选项和代价让他选。
5. **讲清楚**：每步用「做了什么 → 结果 → 为什么」；不懂的概念一两句话解释；报错先说清错在哪、原因、打算怎么修，等他同意再动手。
6. **页面一变就截图给他看**（用户多次强调的硬要求）：用 878 宽预览读图后再决定点击坐标，或直接给他 PNG。
7. **Git**：提交前先列文件清单确认；信息 `Day X｜一句话说明`；回退只用 `git revert`（保留历史），**禁止** `git reset --hard` 和强推。
8. **反复失败就停**：同一个操作连着失败，停下报告「试了什么 / 报什么错 / 判断原因」，不要循环重试。
