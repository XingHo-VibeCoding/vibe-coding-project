## 二、CORS 实测（验收项 2 / 6 的补充证据）

| 请求 | 结果 |
|---|---|
| `GET /api/health` + `Origin: https://vibecoding-test-d5fqmhbb955e19dd-1499011319.tcloudbaseapp.com` | `200`；`access-control-allow-origin: https://vibecoding-test-d5fqmhbb955e19dd-1499011319.tcloudbaseapp.com`、`access-control-allow-credentials: true` |
| `GET /api/health` + `Origin: https://evil.example.com` | `200`，但**没有任何 `access-control-*` 响应头** ⇒ 恶意站点浏览器读不到响应 |
| `OPTIONS /api/list` + 白名单 Origin + `Access-Control-Request-Method: GET` | `204 No Content`；`access-control-allow-methods: GET`、`vary: Origin,Access-Control-Request-Method,Access-Control-Request-Headers` |

即：跨域不是 `*`，也不回显任意 Origin，只放行静态托管域名——与 `docs/api-contract.md:154` 的登记一致。
